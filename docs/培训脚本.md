# HIP 平台分角色培训脚本（试点版，v6 校订于 2026-10-01 / 对应 v1.7.0）

> 每个角色 15-20 分钟上手。演示账号统一密码 `Demo1234`。
> **正式账号首次登录会强制改密（⚠ 新）**——管理员发的初始口令登录后弹出不可关闭的改密窗，
> 改完自动重新登录；90 天到期提醒照旧。
> 训前准备：讲师用 admin 运行 `python tools/bootstrap-demo.py` 引导演示数据。
>
> **讲师须知**：本脚本已按 v1.1.3–v1.2.6 与 v1.5.7–v1.7.0 的用户可见变更校订（日结口径、出院召回、
> 双层锁定、体征校验、运维巡检、错误码速查表）。**照旧版讲会与系统实际不符**——
> 变更点在下文标注「⚠ 新」。遇到学员报错误码，查 [错误码速查表.md](错误码速查表.md)。

## 通用（所有角色，5 分钟）
1. 登录 → 首页驾驶舱（7 日趋势/待办工作量）；菜单只显示本角色权限内功能
2. **首次登录强制改密（⚠ 新，所有角色第一课）**：初始口令登录即弹改密窗，不改不能进系统；
   新口令须 ≥8 位且含字母与数字。**改密后其他已登录的旧会话立即失效**（含被盗号场景）
3. **自助改密（⚠ 新）**：右上角用户菜单 →「修改密码」，随时可改；改完需重新登录
4. 右上角退出；密码超期系统会在登录时提醒
5. 遇故障：口头报科室联络员 → 联络员在「运维中心→故障台账」登记

## doctor01 · 门诊医生（15 分钟）
1. 门诊医生站：候诊列表 → 接诊 → 病历（主诉/现病史）→ ICD 诊断（拼音首字母检索，第一项为主诊断）
   **⚠ 新 v1.7.0：候诊队列头部「跨日期」切换**（默认近 7 天，上限 92 天；起止倒置或超限报 4080）与**「我的患者」复选框**；
   引用资料抽屉的检验/检查/历史三个页签可按时间区间筛选（「基本资料」页签无时间筛选）
2. 保存病历后注意 **CDSS 建议条**（按主诊断给出的检查/用药路径提示）
3. 处方：搜药品 → 用法频次 → 开立。体验三类拦截：过敏禁忌、限制级抗菌药无权限（4014）、配伍禁忌（头孢×藿香正气 4015）
4. 检查检验：开单后患者去收费；报告回来医嘱自动转已执行，危急值弹提醒必须点确认
   **⚠ 新 v1.7.0：开单页签按类别露出录入项**——检验行填标本类型/采样部位/临床摘要/注意事项；检查行填检查目的/临床摘要/注意事项；
   各行（含处方页签的药品行）有「加急」与「备注」；输入长度与库列宽一致，超长输不进去
5. 病历签名 → 冻结不可改；患者 360 视图看历史
   **⚠ 新 v1.7.0**：患者全景新增「全文检索」页签（空关键字不发请求；结果满 50 条提示「仅显示前 50 条」）；文档弹窗「导出标准文档（XML）」仅系统管理员/质控可见；
   **改诊断后旧值留痕**（无界面，口径：改诊断算改病历，供质控查询；讲一句即可）
6. **⚠ 新 v1.7.0 按既往病历新建 / 存为模板**：「按既往病历新建」——取清单 → 选一份 → 取正文 → 插入选定段，最后仍须点「保存病历」；
   「存为模板」仅在病历已保存后出现，正文过长会被截断并如实提示
7. **⚠ 新 v1.7.0 模板下拉按使用范围与授权过滤**：全局/全院模板人人可见，科室模板限本科室与被授权者，个人模板仅本人与被授权者；
   门诊结构化模板栏进页即加载（此前从未渲染）。演示账号 doctor01 现已挂内科门诊；演示前若按科室看不到模板，先重跑 `tools/bootstrap-demo.py`（对老库幂等）
8. **⚠ 新 v1.7.0 「已开医嘱」页签「打印单据」**：处方笺 / 检验申请单 / 检查申请单 / 治疗单 / 导诊单；检验行有「报告」按钮（打印检验报告单）。
   讲清口径：**作废医嘱不上纸**、署名印开单医师、诊断印「疑似…（疑诊）」与「[中医]」、过敏史并印档案文本与结构化记录、**已退号的挂号拒印（4893）**；
   Ctrl+P 已去掉侧栏与顶栏。**导诊单不印加急/备注**（设计如此）。演示前置：需 admin 先排班、挂号，再由 doctor01 开四类医嘱；演示患者若无出生日期，各单「年龄」显示「—」

## 住院医生（⚠ 新增节，10 分钟；演示用 admin 账号）
> **演示账号说明**：`doctor01` 只有门诊医生角色，**没有「住院医生站」菜单**；本节一律用 admin 账号演示。
1. **在院一览表**：新增「年龄」「主治医生」两列
2. **住院医生站「病历」页签**：只读的「病历完整性」提示——写一条病程后「还缺 N 项」实时减少；**只读不拦**，不会因为缺项不让保存
3. **开药 / 开申请**：行内有「备注 / 注意事项 / 加急」；开立后清空，**切换患者时自动清空**（不会把 A 的备注带到 B 的医嘱上）；护士站同步显示这三项
4. **取模板**按**登录医生所在科室**（不再是患者所在科室）
5. **住院病历留版本**：新增、三级查房、签名都会留版本行，审签可据此绑定

## nurse01 · 护士（15 分钟）
1. 门诊护士站：静脉药收费后进输液候选 → 皮试登记（青霉素类必须阴性才能开始输液）→ 输液 → 巡视 → 结束
2. 住院：护士执行（执行医嘱扣库存）、生命体征录入 → 体温日历自动标发热日
   **⚠ 新 v1.7.0**：护士站「待执行」与长期医嘱执行行两张表新增「备注 / 注意事项」列，加急显示红标（历史医嘱显示「—」）；
   **长期医嘱不再出现在待执行队列**（此前点「执行」会报 9125），只走下方执行行表
3. 风险评估：Braden/Morse 评分 → 自动分级 → 高危患者进预警清单，复评降级自动移出
4. 移动工作台（/m）：手机上点患者 → 抽屉录体征。
   **⚠ 新：体征就地校验**——中文句号自动纠正（"36。5"→36.5），非数字或超量程
   （体温 30–45、脉搏 20–250 等）当场拦截。此前这类输入会静默存成空值且照弹成功提示
5. 传染病报卡：报卡（甲类 2 小时时限提示）→ 等院感科审核上报

## cashier01 · 收费员（10 分钟）
1. 门诊挂号：选患者 → 选号源 → 挂号（满号自动拦截）；退号（已收费需先退费）
   **⚠ 新 v1.7.0**：挂号列表新增「凭条」按钮（打印挂号凭条，已退号的不显示）
2. 门诊收费：点患者 → 支付方式（现金/微信/支付宝/医保）→ 收费；医保单自动做费用分割
   **⚠ 新 v1.7.0**：门诊收费台有「打印单据」入口（处方笺/申请单等，口径同医生站：作废行不上纸、已退号挂号拒印）
3. 扫码支付台：出码 → 患者扫码（演示用「模拟扫码」）→ 自动结算
4. **日结报表（⚠ 新口径，必讲）**：收款按**收款日**、退款按**退费日**各自归集——
   昨天收今天退的单出现在**今天**的报表，历史日报表不再"事后变脸"。
   CSV 列＝`口径,结算单号,患者,金额,方式,发生时间`：收款/退款各成一行、**退款金额为负**，
   金额列直接求和＝当日净额。演示：造一笔昨日单今日退，翻两天报表看差异
5. **交款核对（⚠ 新）**：退款计入**退费操作员**名下（甲收乙退各归各）；重名员工按账号各自一行
6. **建档表单**：身份证 18 位/手机 11 位就地校验；
   **编辑已有档案时回显的脱敏值（含 `*`）不能直接保存**，须重录完整号码——这是防止把真实号码覆盖成掩码
7. **医保模块停用时（多院场景）**：未采购医保的院区，收费选医保方式会被明确拒绝（5010）；
   但**历史分割与对账记录仍可查、已收医保单仍可退**——查询与冲销不受开关影响，对账有据
8. **大额退费审批（⚠ 新 v1.3.0，必讲）**：超过阈值（默认 500 元，院内可配）的退费不能直接退——
   点退费会提示「需授权人审批」→ 填原因提交申请 → 授权人（管理员）在「退费审批台」通过后才能退。
   演示：造一笔大额单点退费看拦截 → admin 到退费审批台通过 → 收费员再退成功。
   小额退费（未超阈值）仍直接退，无变化。阈值设 0 = 关闭审批全部直退

## 住院收费（CASHIER/ADMIN，⚠ 新增节，10 分钟）
1. 住院业务 → 在院/出院患者 → **出院结算**（押金自动冲抵，应退/应补当场显示）
2. **结算冲销（出院召回）**：结算错误的唯一系统内纠正路径——
   点「结算冲销」→ 患者恢复在院 → 改医嘱 → 重新结算（单号自动新发，不与作废单冲突）
   - 原床已被新患者占用时，须指定一张空床
   - 医保单会自动发冲正报文；提示 **9026 医保冲正失败**时联系医保办，
     此时本地不会留半截账（整笔回滚，可安全重试）
3. **住院中间结算（⚠ 新 v1.3.0）**：长住/医保患者住院期间可做阶段性结算——按已发生费用出一张
   中间结算单（不出院、不影响押金冲抵口径）。**关键**：中间结算只结"新发生"部分，多次中间结算
   互不重叠；出院结算仍按全部医嘱台账现算，**不会**把中间结算叠加进去（不会重复收费）。
   医保患者的中间结算仅本地留痕、不发医保报文（分段上传留实施期对接）
4. 演示要点：冲销前后各看一次患者状态与结算单状态，让学员理解"可纠正"而非"改库"

## 患者端（对外演示，5 分钟）
