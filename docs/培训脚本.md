# HIP 平台分角色培训脚本（试点版，v4 校订于 2026-08-28 / 对应 v1.3.0）

> 每个角色 15-20 分钟上手。演示账号统一密码 `Demo1234`。
> **正式账号首次登录会强制改密（⚠ 新）**——管理员发的初始口令登录后弹出不可关闭的改密窗，
> 改完自动重新登录；90 天到期提醒照旧。
> 训前准备：讲师用 admin 运行 `python tools/bootstrap-demo.py` 引导演示数据。
>
> **讲师须知**：本脚本已按 v1.1.3–v1.2.6 的用户可见变更校订（日结口径、出院召回、
> 双层锁定、体征校验、运维巡检、错误码速查表）。**照旧版讲会与系统实际不符**——
> 变更点在下文标注「⚠ 新」。遇到学员报错误码，查 [错误码速查表.md](错误码速查表.md)。

## 通用（所有角色，5 分钟）
1. 登录 → 首页驾驶舱（7 日趋势/待办工作量）；菜单只显示本角色权限内功能
2. **首次登录强制改密（⚠ 新，所有角色第一课）**：初始口令登录即弹改密窗，不改不能进系统；
   新口令须 ≥8 位且含字母与数字。**改密后其他已登录的旧会话立即失效**（含被盗号场景）
3. **自助改密（⚠ 新）**：右上角用户菜单 →「修改密码」，随时可改；改完需重新登录
4. 右上角退出；密码超期系统会在登录时提醒
5. 遇故障：口头报科室联络员 → 联络员在「运维中心→故障台账」登记

## doctor01 · 门诊医生（15 分钟）
1. 门诊医生站：候诊列表 → 接诊 → 病历（主诉/现病史）→ ICD 诊断（拼音首字母检索，第一项为主诊断）
2. 保存病历后注意 **CDSS 建议条**（按主诊断给出的检查/用药路径提示）
3. 处方：搜药品 → 用法频次 → 开立。体验三类拦截：过敏禁忌、限制级抗菌药无权限（4014）、配伍禁忌（头孢×藿香正气 4015）
4. 检查检验：开单后患者去收费；报告回来医嘱自动转已执行，危急值弹提醒必须点确认
5. 病历签名 → 冻结不可改；患者 360 视图看历史

## nurse01 · 护士（15 分钟）
1. 门诊护士站：静脉药收费后进输液候选 → 皮试登记（青霉素类必须阴性才能开始输液）→ 输液 → 巡视 → 结束
2. 住院：护士执行（执行医嘱扣库存）、生命体征录入 → 体温日历自动标发热日
3. 风险评估：Braden/Morse 评分 → 自动分级 → 高危患者进预警清单，复评降级自动移出
4. 移动工作台（/m）：手机上点患者 → 抽屉录体征。
   **⚠ 新：体征就地校验**——中文句号自动纠正（"36。5"→36.5），非数字或超量程
   （体温 30–45、脉搏 20–250 等）当场拦截。此前这类输入会静默存成空值且照弹成功提示
5. 传染病报卡：报卡（甲类 2 小时时限提示）→ 等院感科审核上报

## cashier01 · 收费员（10 分钟）
1. 门诊挂号：选患者 → 选号源 → 挂号（满号自动拦截）；退号（已收费需先退费）
2. 门诊收费：点患者 → 支付方式（现金/微信/支付宝/医保）→ 收费；医保单自动做费用分割
3. 扫码支付台：出码 → 患者扫码（演示用「模拟扫码」）→ 自动结算
4. **日结报表（⚠ 新口径，必讲）**：收款按**收款日**、退款按**退费日**各自归集——
   昨天收今天退的单出现在**今天**的报表，历史日报表不再"事后变脸"。
   CSV 列＝`口径,结算单号,患者,金额,方式,发生时间`：收款/退款各成一行、**退款金额为负**，
   金额列直接求和＝当日净额。演示：造一笔昨日单今日退，翻两天报表看差异
5. **交款核对（⚠ 新）**：退款计入**退费操作员**名下（甲收乙退各归各）；重名员工按账号各自一行
6. **建档表单**：身份证 18 位/手机 11 位就地校验；
   **编辑已有档案时回显的脱敏值（含 `*`）不能直接保存**，须重录完整号码——这是防止把真实号码覆盖成掩码
7. **医保模块停用时（多院场景）**：未采购医保的院区，收费选医保方式会被明确拒绝（5010）；
   但**历史分割与对账记录仍可查、已收医保单仍可退**——查询与冲销不受开关影响，对账有据
8. **大额退费审批（⚠ 新 v1.3.0，必讲）**：超过阈值（默认 500 元，院内可配）的退费不能直接退——
   点退费会提示「需授权人审批」→ 填原因提交申请 → 授权人（管理员）在「退费审批台」通过后才能退。
   演示：造一笔大额单点退费看拦截 → admin 到退费审批台通过 → 收费员再退成功。
   小额退费（未超阈值）仍直接退，无变化。阈值设 0 = 关闭审批全部直退

## 住院收费（CASHIER/ADMIN，⚠ 新增节，10 分钟）
1. 住院业务 → 在院/出院患者 → **出院结算**（押金自动冲抵，应退/应补当场显示）
2. **结算冲销（出院召回）**：结算错误的唯一系统内纠正路径——
   点「结算冲销」→ 患者恢复在院 → 改医嘱 → 重新结算（单号自动新发，不与作废单冲突）
   - 原床已被新患者占用时，须指定一张空床
   - 医保单会自动发冲正报文；提示 **9026 医保冲正失败**时联系医保办，
     此时本地不会留半截账（整笔回滚，可安全重试）
3. **住院中间结算（⚠ 新 v1.3.0）**：长住/医保患者住院期间可做阶段性结算——按已发生费用出一张
   中间结算单（不出院、不影响押金冲抵口径）。**关键**：中间结算只结"新发生"部分，多次中间结算
   互不重叠；出院结算仍按全部医嘱台账现算，**不会**把中间结算叠加进去（不会重复收费）。
   医保患者的中间结算仅本地留痕、不发医保报文（分段上传留实施期对接）
4. 演示要点：冲销前后各看一次患者状态与结算单状态，让学员理解"可纠正"而非"改库"

## pharm01 · 药师（10 分钟）
1. 药房发药：已收费处方 → 发药（自动扣库存）；退药（RET 流水回补）
2. 审方工作台：拒绝即处方作废（医生需重开）
3. **入库验收（⚠ 新 v1.3.0）**：入库不再"即入账"——先记**待验收**，质检通过点「验收」才真正加库存；
   有质量问题点「拒收」不加库存并记原因。演示：入库一批 → 待验收列表 → 验收通过看库存增加
4. **库存盘点（⚠ 新 v1.3.0）**：月末实物盘点——建盘点单 → 逐药录**实盘数** → 系统算账实盈亏 →
   确认后按盈亏调库存并记 STOCKTAKE 流水。演示：建盘点单、录一个与账面不符的实盘数、看盈亏、确认调库
5. **近效期预警（⚠ 新 v1.3.0）**：近效期药品列表（默认 90 天内，可调），每日自动巡检开提醒工单。
   **注意口径**：在库量是**按先进先出估算**（非精确批次追溯），作预警提示用，具体近效期批次以实物为准
6. 药事分析：用药 TOP、抗菌药使用强度 AUD（国考 ≤40 参考线）

## tech01 · 医技技师（10 分钟）
1. 预约与叫号：已收费申请单排时段（AM/PM 自动顺序号）；改约/批量取消
2. LIS：采样打码（**替检要登记替检人**，分检页红色标识）→ 核收 → 录结果发布（HH/LL 自动危急值+自动执行医嘱）
3. RIS：心电/内镜/超声按模态过滤 → 报告 → 审核发布（发布即出 72h 分享短链给患者）
4. 病理：取材 PB 码 → 核收 → 诊断报告

## quality01 · 质控院感（15 分钟）
1. 院感专项：三管置管登记 → 每日评估 → 拔管/判定感染（自动联动院感病例）→ 千日感染率
2. 现患率调查：一键生成在院快照
3. 传染病报卡：审核 → 上报闭环
4. DRG 分析：批量入组 → 病组/CMI/费用消耗指数；补录其他诊断后「重新入组」看细分组变化
5. 病案统计：疾病谱/手术/科室构成；单病种：入组建议 → 建卡 → 上报

## ops01 · 运营后勤（10 分钟）
1. 设备管理：报修 → 派工 → 完成；保养到期红标 → 执行自动顺延；计量/证照到期预警
2. 采购单据：备货 → 审核 → 验收补发票 → 退货；作废可还原
3. 人事管理：员工档案、工资粘贴导入、继续教育学分、考勤打卡/补卡
4. 窗口与科研：窗口开关、科研台账审核

## 患者端（对外演示，5 分钟）
手机访问 `/portal`：患者号+手机号登录 → 预约挂号 → 待缴费扫码支付（模拟回调）→ 检验报告（危急值显示"请回院复诊"）→ 检查/病理报告 → 智能导诊（输症状荐科室）

**⚠ 新：登录保护双层**——同患者号连续错 5 次锁 15 分钟；跨设备累计错 50 次/小时触发全局锁。
**锁定期内输入正确手机号也会被拒（9503）**，这是正常保护而非故障；导医台遇患者反映"密码对却进不去"，
请其等窗口过后再试，勿反复重试（每次失败都会延长）。

## admin · 系统管理员与运维（⚠ 新增节，15 分钟）
1. **运维中心 /ops**：健康概览（数据库/磁盘/运行时长）、故障工单台账、慢接口、备份记录
2. **巡检手动触发（⚠ 新）**：`POST /api/ops/inspections/run` 或运维页按钮——
   返回本轮开单数，用来当场验证"告警在不在工作"，不必等每小时 cron。
   演示：故意把磁盘监测路径配错 → 触发 → 看到 MEDIUM 工单开出 → 改回 → 处理工单
   - 同一问题未处理时不会重复开单（不刷屏）；工单处理后问题仍在会重新开单（不静默）
3. **备份与恢复**：每日 02:30 自动备份（任务计划 HIP-DailyBackup）；
   **恢复演练判据**——不是"能连上"就算过，须逐表比对源库与恢复库计数，并用恢复库启动一次跑通业务
4. **错误码支持**：[错误码速查表.md](错误码速查表.md) 覆盖 268 个业务码的含义与处置；
   其中 26 个码在不同模块含义不同，**按码查询时先确认发生在哪个模块**
5. **账号发放纪律（⚠ 新）**：建号/重置口令后用户**首次登录必被强制改密**（1009）——
   给用户报初始口令时提前说明，避免"登不进去"的误报；用户忘口令走管理员重置，同样触发强制改密
6. **模块开关（⚠ 扩）**：新增「临床数据中心」「数据治理」两项可按院关闭；
   停用医保后历史对账仍可查（有意豁免，不是开关失效）
7. **数据库主备（⚠ 新）**：对 RPO/RTO 有要求的院区按部署手册附录搭流复制主备；
   切换纪律「先停应用、后动库、切完冒烟」，演练全流程见彩排记录 §九
8. **病案复印（⚠ 新 v1.3.0，病案室/质控）**：患者法定复印病历——受理复印申请（患者/范围/用途/份数）→
   登记（生成复印登记号）→ 出**复印件**（带"复印件"水印与登记号，全程留痕谁申请、复印了什么、谁经办）
9. **权限按钮已细化（v1.3.0）**：收费/退费/发药/退药/用户停用等危险按钮现按角色显示——
   收费员看不到发药按钮、药师看不到退费按钮。若某角色反映"按钮不见了"，先核对其角色授权
10. 用户与角色：**接口机账号（LIS/中间件）一律授 INTERFACE 角色**，严禁给 admin 凭据
9. 配置维护：机构参数在系统配置；**保存即校验**（比例须 0–1、开关须 0/1，填错当场拒绝）；
   经管理页改即时生效，**直改数据库最长延迟 30 秒**
