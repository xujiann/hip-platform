## 债一：server 模块聚合控制器裁决（优先级最高）

`server/src/main/java/cn/hip/server/web/` 现有控制器逐一裁决：

| 控制器 | 预判 | 理由 |
|---|---|---|
| StatsController | 留 server | 真跨模块驾驶舱聚合 |
| MedRecordStatsController / DrugAnalysisController | 留 server | 跨模块统计 |
| DrgController | 可下沉 qualitycare | 仅依赖 inp_* + drg_*，与病案/质控同域 |

| PriceFinanceController | 拆：价格→masterdata，交款核对留 server | 价格属主数据域 |
| OpsController + SlowApiFilter + AuditLogFilter | 留 server | 平台横切关注点 |
| QueueCenterController | 可下沉 outpatient | 三队列数据源均门诊侧 |
| PrintReportController | 拆：审计查询→core，打印/日结留 server | 审计属平台 |
| InsuranceSplitTest 等测试 | 随迁移同步改 import | 见 memory 教训：git mv + sed 包名 |

方法：git mv + 包名 sed + pom 依赖核对（参考十八期下沉四模块的做法，提交 b97c811）。每迁一个跑一次 `mvn -q test`。
