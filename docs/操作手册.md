# HIP 平台分角色操作手册（速查版）

> 登录地址：`http://<服务器>/`；患者端：`/portal`。首次部署默认管理员 admin/admin123（登录后立即修改）。
> 密码规则：≥8 位且含字母和数字；连续错 5 次锁定 15 分钟。

## 收费员（角色 CASHIER）
1. **挂号**：门诊业务→门诊挂号：搜患者（无档先到「患者建档」）→选号源→挂号，凭条在 `/print?type=registration&id=挂号ID` 打印
2. **收费**：门诊业务→门诊收费：左侧队列选患者→核对明细→选支付方式→收费；票据打印 `/print?type=charge&id=结算单ID`
3. **退费**：收费页下方「最近结算单」→退费（已发药需药房先退药）
4. **日结**：运营管理→日结报表：核对当日各支付方式金额，导出 CSV 交财务

## 门诊医生（角色 DOCTOR_OUTP）
1. 门诊业务→门诊医生站：左侧队列点患者→「接诊」（或先在叫号大屏叫号）
2. 病历页填写主诉/现病史/查体，搜索 ICD 诊断（支持拼音首字母）→保存；确认无误后**签名**（签名后冻结不可改）
3. 处方页选药品与用法→开立（过敏/重复用药会被自动拦截）；检查检验页提交申请
4. 患者缴费后流转至药房/医技，无需医生操作

## 药师（角色 PHARMACIST）
1. **审方**：门诊业务→审方工作台：逐条通过/拒绝（拒绝需填原因，处方即作废）
2. **发药**：门诊业务→药房发药：按患者点「发药」；**退药**在同页下方选患者操作
3. **药库**：基础数据→药库管理：入库（批号/效期）、盘点调整、关注低库存预警

## 护士（住院）
1. 住院业务→护士执行：执行医嘱（药品执行自动扣库存）；上方录入生命体征
2. 住院业务→护理白板：全病区一览，可直接调整护理级别
3. 危急值告警出现后须及时处理并记录

## 医技（检验/检查）
1. **LIS**：门诊业务→LIS 工作台：待采样→打码；标本流转页核收→录结果→审核发布（发布自动回写医嘱并触发危急值）
2. **RIS**：门诊业务→RIS 报告：书写所见/意见→审核发布；影像调阅入口见 PACS 配置

## 管理员（角色 ADMIN）
- 系统管理：用户/科室/角色授权/审计日志；机构名称等在 `sys_config`（接口 `/api/config/{key}`）维护
- 数据中心：患者 360、质控中心、数据治理（指标快照/填报/质量核查）
- 验收工具：`tools/gen-coverage-matrix.py`（参数清单）→ `tools/matrix-autoreview.py`（初评）→ 人工复核
- 数据迁移：`tools/import-patients.py tools/migrate-templates/patients.csv`

## 患者（/portal）
患者号+建档手机号登录 → 预约挂号 / 我的挂号 / 检验报告 / 费用查询。
