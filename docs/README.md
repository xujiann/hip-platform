## 常见场景快速定位

- **要装一家新医院** → 部署手册 → 配置手册 → 接口现状调研表
- **要替换在用 HIS** → 多医院部署操作指南 §六 → 三件套工具（import-patients / import-inpatients / import-documents）
- **要升级已上线医院** → 部署手册「回滚」节（换包后必查 `/actuator/info`）→ 彩排记录 §五/§六
- **上线后出故障** → 错误码速查表 → 运维中心 /ops（可手动触发巡检）→ 部署手册「运行态验收」
- **要培训院方** → 培训脚本（讲师须知先看）→ 操作手册（发给学员）
- **接手代码** → README → 测试方法论 → 五轮审阅清单（了解已知坑）
