# HIP 配置手册（v1.0，实施工艺包）

> 两层配置：**部署配置**（application.yml / 环境变量，起服务前定）与**运行配置**（sys_config 表，
> 管理页/接口随时改、即时生效）。实施时逐键核对本册；每院的取值随该院配置档案归档。
>
> **即时生效的边界（1.1.4 起）**：经管理页/`PUT /api/config/{key}` 修改即时生效；
> **直接 UPDATE 数据库最长延迟 30 秒**（ConfigReader 缓存），实施现场直改库后请等待或走接口。
> **保存即校验（1.1.3/1.1.6 起）**：比例键须 0–1、开关键须 0/1、`yb_cap_/yb_deductible_/drg_rate`
> 等须非负数字、单号前缀须字母数字——坏值保存被 1402 拦截并提示取值域（填 `abc`/`1.5` 进不去库）。

## 一、部署配置（application.yml / 环境变量）

| 键 | 默认 | 说明 |
|---|---|---|
| `HIP_JWT_SECRET`（环境变量） | dev 占位值 | **生产必设**，≥32 位随机串（`openssl rand -base64 48`） |
| `hip.security.jwt-expiry-hours` | 12 | 令牌有效期（小时） |
| `hip.integration.mllp-enabled` | true | 检验设备 MLLP 监听开关 |
| `hip.integration.mllp-port` | 2575 | MLLP 端口（字符集按 MSH-18 自动识别 GBK/GB18030/UTF-8，单帧上限 1MB） |
| `HIP_MLLP_ALLOW`（环境变量） | 空 | 来源白名单，逗号分隔支持 CIDR；**pilot/prod 留空则拒绝启动监听（fail closed）** |
| `hip.integration.mllp-bind` | 0.0.0.0 | 监听绑定地址（生产建议绑内网接口卡） |
| `hip.integration.mllp-max-conn` | 16 | 并发连接上限（按设备/中间件数量估） |
| `hip.ops.disk-paths` | 空=工作目录 | 磁盘告警监测路径，逗号分隔多卷——**试点应配数据库卷+备份卷** |
| `hip.integration.pacs-url` | http://127.0.0.1:8042 | Orthanc/PACS 地址 |
| `hip.integration.ai-url` | http://127.0.0.1:8100 | ai-service 地址（缺席自动降级） |
| `hip.ops.slow-ms` | 500 | 慢接口观测阈值（毫秒） |
| `spring.datasource.url/username/password` | — | 每院独立库连接 |
| `spring.profiles.active` | — | 试点/生产用 `pilot`（见 application-pilot.yml） |

## 二、运行配置（sys_config，共 33 键）

### 机构与品牌
| 键 | 默认 | 说明 |
|---|---|---|
| `hospital_name` | 示范医院 | 医院全称（登录页/单据抬头/患者端联动） |
| `hospital_short` | HIP 示范医院 | 简称（侧栏标题） |
| `receipt_title` | 示范医院收费专用 | 票据抬头 |
| `contact_phone` | 0000-0000000 | 咨询电话（患者端展示） |

### 模块开关（'1'=启用；关闭=菜单+API 双关闭）
`module.drg.enabled` ｜ `module.cdss.enabled` ｜ `module.insurance.enabled` ｜
`module.blood.enabled` ｜ `module.hr.enabled` ｜ `module.surgery.enabled` —— 默认全启用，
未采购模块实施时置 0（init-hospital 配置 modules 段一次生效）。

### 医保待遇与审核（模块 insurance）
| 键 | 默认 | 说明 |
|---|---|---|
| `yb_ratio_staff` / `yb_ratio_resident` | 0.85 / 0.70 | 职工/居民**门诊**统筹比例 |
| `yb_ratio_staff_inp` / `yb_ratio_resident_inp` | 0.85 / 0.70 | 职工/居民**住院**统筹比例 |
| `yb_deductible_staff` / `yb_deductible_resident` | 0 | 年度起付线（0=不启用；启用后可报销基数先扣起付） |
| `yb_cap_staff` / `yb_cap_resident` | 0 | 年度统筹封顶线（0=不封顶） |
| `yb_audit_qty_limit` | 5 | 审核 R001 单品种数量上限 |
| `yb_audit_self_ratio_limit` | 0.5 | 审核 R003 自费占比提醒阈值 |
| `yb_auto_recon_enabled` | 1 | 每日 01:30 自动对账（差异>0 自动开运维工单） |

> 起付线/封顶线按院方医保政策填；比例按参保类别与医院等级填。全 0 时分割算法与逐行比例口径逐分一致。

### 业务参数
| 键 | 默认 | 说明 |
|---|---|---|
| `drg_rate` | 100 | DRG 支付费率（元/权重，支付模拟） |
| `lis_allow_substitute` | true | 检验替检开关（false 时替检采样拦截 4770） |
| `review_pending_limit` | 0 | 审方工作台单次待审列表上限（0=不限，1.0.1） |
| `empi_idcard_checksum` | 1 | 建档/修改校验身份证校验位（0=关闭，存量迁移含历史假号时用，1.0.3） |
| `cdr_auto_sync_enabled` | 1 | CDR 每日 02:10 自动增量同步（0=关闭，1.0.4）；水位键 cdr_sync_watermark 自动维护 |
| `ops_auto_health_enabled` | 1 | 每小时自动巡检（备份时效/慢接口/磁盘），异常自动开故障工单（0=关闭，1.0.5） |

### 单据编号前缀（1.0.1，默认与历史一致）
`billno_prefix_charge`=SJ ｜ `billno_prefix_admission`=ZY ｜ `billno_prefix_settle`=CY ｜
`billno_prefix_rx`=CF ｜ `billno_prefix_req`=SQ —— 按院单据规范调整，即时生效（存量单号不回改）。

### 系统内部（勿手改）
`cdr_sync_watermark` —— CDR 增量同步水位，由同步任务维护。

## 三、修改途径
- 管理页：系统管理相关页面 / 医保管理页（目录与比例联动展示）
- 接口：`PUT /api/config/{key}?value=...`（ADMIN，进审计）
- 批量：init-hospital 配置 JSON（`hospital.extraConfig` 段可写任意键）

> 新增配置键的纪律：随迁移插入默认值 + remark 必填 + 本册同步补一行。
