# 前言与导读

## 这本书讲什么

这是一本讲**医院信息化如何真正落地**的教材。它有两条线：一条是原理线——医院业务如何运转、行业标准如何约束、架构如何取舍、医保如何计算；另一条是工程线——以一个真实迭代到 v1.0.0 定版的医院信息平台（书中称 HIP）为贯穿案例，把每个原理落到可对照源码的实现上。

市面上的医院信息化读物大致两类：概念型教材把术语讲全但落不了地，厂商文档把操作讲细但讲不出为什么。本书想占住中间那块空地：**每一节先讲这类问题的通用解法与业界方案，再剖析一种真实落地的做法**——包括它的取舍、简化，以及踩过的坑。书中的"教训案例"（如医保结算号未持久化、增量同步水位线漏抓）都是真实发生的返工，我们选择原样呈现而非事后美化，因为返工的逻辑比成功的结论更有教学价值。

## 读者对象

- **医院信息科工程师**：把全书当作系统建设与选型的参考框架，重点读架构篇、工程篇；
- **HIS 开发与实施人员**：业务篇与第 14 章实施方法论是为你写的，案例代码可直接对照工作；
- **医学信息类专业高年级本科生与研究生**：按篇章顺序通读，配合附录 B 的实训环境完成各章练习。

阅读前置：了解基本的数据库与 Web 开发概念即可；代码示例以 Java/SQL 为主，但重点从来不是语法，而是模型与取舍。

## 体例约定

- **案例框**：编号为「案例框 N-x」的引用块是 HIP 真实实现的剖析，类名、表名、代码片段均可在配套仓库中对照源码；
- **业务场景框**（第 2 章）：以具体患者与角色的叙事串联流程，场景对应真实功能页能力；
- **【成稿核对：××】**：涉及政策文号、标准版本、评级条目数等外部事实，写作时无法当场核实的，以此标注保守处理——正式出版前须逐条对照最新官方文件核定，全书共约 60 处；
- **诚实披露**：凡 HIP 的实现相对行业完整形态有简化（如目录为示例集、某链路未任务化），正文以「当前简化/演进方向」口径明示，不虚构能力。部分真实缺陷被有意保留为教学点与习题（对应修复工作在平台侧另行进行）。

## 配套资源

- **实训环境**：附录 B 给出完整搭建指南（Java 21 + Spring Boot 3.5 + PostgreSQL 16 + Vue 3），一台普通开发机即可运行全部实验；
- **各章习题**：概念、计算、设计、排障、论述、实践六类，实践题均可在实训环境中完成，附录 B 附有习题与模块的对应表。

本书全部案例源自 HIP 平台从零到 v1.0.0 的真实开发历程——55 个功能页、44 个数据库迁移版本、19 套端到端测试套件，以及贯穿其中的架构决策记录与版本规划文档。感谢这段工程实践本身：它证明了中小医院的信息化可以在有限资源下做到工程上的体面，这也是本书最想传递的信念。
