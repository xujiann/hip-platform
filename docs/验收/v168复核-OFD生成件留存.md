# v168 OFD 生成件留存复核

住院历史病历版本支持生成并留存未签署 OFD、查看最近 50 件及取回原文件。每次生成追加独立文档标识，文件、来源指纹和原患者及住院关联在同一事务保存。写入后复核当前权限，失败时回滚。列表和取回也复核当前权限。下载校验长度及 SHA-256，直接返回保存的原始字节。

新增 V185 表保存完整 bytea、文件摘要和长度、来源版本 ID、版本号和摘要、原患者及住院关联、生成员工及时间。每次 POST 独立追加。列表仅查元信息，最多 50 件，按生成时间及 ID 倒序。原关联不符的旧件从列表过滤，指定下载时拒绝请求。文件完整性校验失败时拒绝取回。

渲染在事务外完成。独立 READ COMMITTED 短事务插入后复核当前员工、岗位、原关联和来源指纹。大文件读取及摘要计算后再次复核，并发判定边界为末次 SQL 快照。数据库触发器拒绝普通 UPDATE/DELETE，数据库所有者拥有触发器管理权限。

前端在明确选择的住院历史版本中操作，展示六项元信息。生成按钮互斥。关闭、重开、切换病历或版本后，页面会丢弃旧回包。读取原件与重新生成分别提供入口，网络结果未知时提示先查询确认。
