## 我另查到的格子

逐格过五张单据，只列"取值列/修饰列有问题"或"值得标注"的；无问题的不列。

1. **导诊单行序与"按上表顺序"自相矛盾（R1，唯一涉及纸面内容的新发现）**。PC:293 `order by o.order_type, o.id`，order_type 是字符串，字母序为 DRUG、EXAM、LAB、TREAT；PV:315-316 温馨提示写"再持本单按上表顺序到对应科室完成各项目"。复现：同一就诊既开药又开检验，两者均已缴费 → 序 1=取药、序 2=检验，纸上指示患者先取药后验血。用例 T43:227-243 自己 `.sorted()` 后才比较，**没有断言行序**。这是"纸上一句话与纸上数据矛盾"，不是事实性数据错（每一行本身都对）。修法二选一：提示改成"缴费后各项目可依次办理，请按窗口指引"，或 SQL 按 检验/检查→治疗→取药 的业务序排。审计者与自查都没提。
