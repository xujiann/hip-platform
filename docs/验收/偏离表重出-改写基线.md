# 改写质量基线 —— 主控事先写下"好的对外应答长什么样"，用于事后校验 39 个改写 agent

与审计时同一纪律：先立独立标准，再看 agent 输出；否则无法判断改写是过宽还是过严。

## 校验维度（每条 0/1）
1. **不超出审计结论**：new_note 里描述为"已提供"的能力，必须是 evidence/audit_note 确认存在的
2. **缺项不少列**：部分符合的缺项列表 ≥ audit_note 所列
3. **对外语言干净**：无 file:line / 类名 / 表名 / grep / 审计 / 判定 字样（装配器正则兜底）
4. **无承诺越权**：不出现时限、版本号、"X 天内"
5. **档位正确**：符合→正偏离/无偏离；部分/不符合→部分响应；红线/医保规范→外部条件；商用产品→配套产品响应
6. **★ 降级必标 needs_human**
7. **法规冲突写澄清**：1341 / 1161 不能简单降级

## 参照样本（我认为的合格答案）

### 2025 ★ 体温单 —— verdict 符合（v1.4.2 交付）
- 结论：正偏离/无偏离
- 说明：住院护士站与医生站提供电子体温单（三测单）：按住院周查看，支持页面缩放，体温/脉搏/呼吸曲线与出入量、大便次数、体重等底栏项完整，可直接打印为病历组成部分。
- needs_human：否

### 991 ★ 门诊病历签名 —— verdict 不符合（端点在、前端无按钮）
- 结论：部分响应
- 说明：门诊医生站已具备病历电子签名的后台服务能力；当前版本医生操作界面尚未提供签名操作入口，列入后续开发计划。
- needs_human：**是**（★ 降级）
- 反例（不合格）："签名端点 DoctorStationController:94 已实现" —— 内部词；"已实现签名" —— 超出结论

### 1026 ★ 五种日常单据打印 —— verdict 不符合（零实现）
- 结论：部分响应
- 说明：平台已提供挂号凭条、收费票据、检验报告单、住院费用一日清单、出院小结、体温单、护理记录单的打印；处方笺、检验申请单、检查申请单、治疗单、导诊单五类单据打印当前版本尚未提供，列入后续开发计划。
- needs_human：是（★ 降级）
- 要点：把"已提供"写具体，是诚实的加分项；不能因为要降级就把整段写成"未提供"

### 542–558 CA 簇 —— verdict 属外部边界
- 结论：配套产品响应
- 说明（同簇用语一致）：本条属 CA 数字证书厂商产品范畴。平台已提供标准电子签名接入点（签名适配器），可对接符合国家规范的第三方 CA 签名服务；CA 服务器、签名客户端、移动签名 APP 及相关检测证书由 CA 厂商配套提供。
- needs_human：否（非★）

### 29 ★ 四川省医保接口规范 —— verdict 属外部边界
- 结论：**外部条件**（不是配套产品——它是医保部门的规范与联调环境）
- 说明：本条依赖四川省医保部门提供的接口规范与联调环境。平台已提供医保接入适配层，接口规范与测试环境到位后即可对接。
- needs_human：是（★ 且改外部条件）

### 131 ★ 兼容国产操作系统 —— verdict 非软件功能条款
- 结论：部分响应
- 说明：平台基于 Java 与 PostgreSQL 构建，具备跨平台运行基础；国产操作系统与数据库的适配将以兼容性测试报告作为响应证据。
- needs_human：是（证据尚不存在，且★）
- 反例："平台已实现国产化兼容" —— 无证据

### 1341 病历删除/回收站 —— verdict 不符合，但属法规冲突
- 结论：正偏离/无偏离 **或** 部分响应（负责人定）
- 说明：依据《病历书写基本规范》，已形成的病历不得删除。平台以"签名冻结 + 补正留痕"替代删除：原文保留、修改可追溯，符合病历管理法规要求。本条所述"删除/回收站"功能因与法规冲突不予提供。
- needs_human：**是**（澄清口径须负责人确认）
- 反例：简单写"未提供，列入后续开发计划" —— 这等于承诺去做一个违规功能

### 1161 盘点期间出入库 —— verdict 不符合，但属刻意设计
- 结论：部分响应（附澄清）
- 说明：平台采用"盘点期间账面变动即整单重盘"的设计，以防止并发出入库污染盘点结果。本条所述"盘点期间出入库自动汇总进盘点单"为另一种口径，如需采用可按医院管理要求调整。
- needs_human：是

### 2734 终末质控自动评分 —— verdict 符合（v1.4.2）
- 结论：正偏离/无偏离
- 说明：病案终末质控模块提供扣分项字典维护、按院内评分标准自动预填扣分项、人工复核、甲乙丙自动评级，并按科室/月度统计甲级率与扣分项分布，支持导出。
- needs_human：否
- 注意：不能写"AI 自动评审"——审计明确这是规则预填不是语义评审

## 校验抽样计划
每波各抽：2 条★ / 1 条 符合 / 1 条 CA 或外部边界 / 1 条 不符合 / 1341 或 1161（若在该波）
对照上表逐维打分；任一波出现"超出审计结论"即整波复核。
