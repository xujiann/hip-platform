## 结论 + 一句理由

**不推翻但须标注的保留项**（R1–R5，其中 R1、R2、R4 必须落进说明或演示前置清单）。理由：评委按培训脚本三处「⚠ 新 v1.7.3」逐步点——tech01 进基础数据建/停/删规则并试算三档、doctor01 加检验行见诊断标签与预填摘要、填标本提交见执行科室提示、申请单与导诊单逐行印执行科室/标本/部位/诊断/摘要、tech01 在 LIS 按执行科室过滤并见执行科室列——每一步在代码与 HTTP 实测上都走得通且看到的与说明一致，规则命中（1841→影像科）、字典回落（1842→检验科）、空值（1843→—）、停用后快照不变四种结果均实测复现；走不通或看不出的地方（演示库演不出分流、执行科室只在 toast 闪一次、双摘要同文、开关无界面）都是演示前置与可见性限定，未把参数字面要求的功能变成不存在。
