# v90 复核：住院知情同意书对象权限

状态：实施与验收中，基线 v1.8.8；尚未定版或推送。

## 本轮修复

住院同意书的默认列表、住院筛选、历史双归属的门诊筛选、详情、创建、患者签名录入及作废统一使用当前住院主管。普通医生仅本人或未指定主管，登录身份必须可解析；同患者另一住院不扩权。集合在100条上限前SQL过滤；详情拒绝1005，写拒绝9018。ADMIN/NURSE保留既有护理协作范围，未建立病区分配模型。

医师CA签署限ADMIN/DOCTOR_OUTP，护士可创建、录入患者签名及作废未生效文书，不能签医师栏；前端按角色隐藏医师签名按钮。SIGNED仅管理员可作废的状态规则不变。

创建要求住院/门诊二选一，复用9110；存量双归属凡含admission_id均按住院权限处理。门诊单归属原契约保持，门诊对象权限列后续。本轮不新增迁移、错误码、菜单、配置或返回键；显式筛选不存在住院沿用9003，同意书不存在9112。

写操作事务中先锁住院记录，按实时主管核验后再锁同意书，锁持有至签名和更新完成。与主管移交共用父行锁；患者签名、医师签名、作废使用一致锁顺序。前端切换患者立即清空旧文书和创建弹窗，并以请求序号防止旧响应覆盖新选择。
