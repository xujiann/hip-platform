## 方法上这轮多学到的一条

agent 引用 v3 时会把「响应结论」列与「响应说明」列**拼成一句**（`响应结论：部分响应。响应说明：…`），
而 CSV 的说明列本身是裸正文。主控据此把新说明也套上了这个前缀，格式修正脚本的断言当场把它打回——
**改对外表格前，格式以 CSV 原文为准，不以 agent 的引用为准。**
