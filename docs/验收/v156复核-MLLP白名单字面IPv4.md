# v156 MLLP 白名单字面 IPv4 复核

MLLP 来源白名单 `HIP_MLLP_ALLOW` 直接解析四段十进制 IPv4 和可选的 0–32 位 CIDR 前缀。主机名、IPv6、缩写地址和格式错误的前缀会在监听绑定前被拒绝。已使用主机名的部署需将其换为对应的固定 IPv4 或 IPv4 网段。

原列表支持条目外侧空白、空项及显式 /0 和 /32。IPv4 每段按十进制计算，CIDR 仍会归一化主机位。回环和空名单的既有策略沿用。部署配置说明已更新。
