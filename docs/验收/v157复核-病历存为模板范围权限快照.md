# v157 病历存为模板范围权限复核

病历存为模板时，系统使用读取来源正文的同一个数据库快照，判定能否建立目标范围的模板。管理员降岗后，即使仍可读病历，也不能据旧岗位创建全局或全院模板。科室模板未指定科室时，按该快照中的当前科室生成模板和自动授权。

## 权限与数据

`POST /api/emr-templates/from-record` 从既有来源 SQL 获取真实员工编号、科室和管理员状态，校对请求所属员工编号，再按原逻辑校验目标范围。临床角色与患者关系由原来源 SQL 检查。模板及自动授权使用该员工编号及科室。历史列表、正文和保存结果的公开字段、病历类型及截断规则沿用原契约。

旧版真实 JWT 回归在门诊和住院各复现四个失败场景。ADMIN 降为 QUALITY 后仍能以 HOSPITAL 或 GLOBAL 保存。QUALITY 转科后，未指定科室的模板和授权落在原科室，显式请求原科室也成功。两个合法 PERSONAL 对照在旧版通过。修复后十个场景全部通过，六次范围拒绝返回 4066，未写模板或授权。两次合法科室保存都落到新科室。来源病历保持原样。

回归在实际来源 SQL 执行前暂停请求，通过公开员工接口独立提交降岗或转科，再让查询继续。V45 历史夹具原先用管理员登录态读取、用医生参数写入，本轮给调用设置同一个医生身份及合法患者关系，保留原断言。含 V152、V45 的定向回归实际 306 项通过。
