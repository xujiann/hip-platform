## 修复与回归

visible、use、grants、default 和 legacyList 的员工画像、对象可见性与正文属于同一次 SQL 快照。外层员工资格行在 payload 为空时仍保留；先拒绝不合格员工，再移除内部资格及父对象标记。原字段读取的四岗、SQL 和共享可见性矩阵保持原样。

合法员工的公开键、原过滤与排序不变。套用不可见模板仍为 4066；默认模板不存在为 null、存在但不可见为 4066；可见父模板没有授权仍为空列表。null/missing 员工及无数据库员工的模拟管理员不再取得模板；supplied admin/dept 无法替代当前数据库资格或扩大范围，合法员工仍按真实画像读取。旧测试按这项明确策略收紧更新。

最终同一版 65 项真实 JWT 用例在旧生产代码中有 30 项失败、35 项控制通过：25 项入口授权后、正文 SQL 前停用或失岗，以及 5 项空结果也必须先拒绝员工。初次测试另有 7 项夹具漏列原 USE scopeName 字段，首跑原件保留；修正夹具后重新取得最终旧版 30 项失败，没有把夹具错误算作产品缺陷。
