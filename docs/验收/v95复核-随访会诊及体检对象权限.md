# v95复核：随访、会诊及体检对象权限

状态：基线v1.8.13，2026-10-18验收通过，本地定版v1.8.14，尚未推送。

## 授权口径与契约

随访新建/完成限ADMIN/DOCTOR_OUTP/NURSE；普通医护只能读取和完成本人创建任务，ADMIN统筹、QUALITY只读；历史null创建人不认领，真实用户解析失败1005。

会诊申请限ADMIN/DOCTOR_OUTP并按当前住院主管或未归属授权，事务锁住院行后检查在院与临床受邀科室；意见完成限ADMIN或数据库当前科室匹配to_dept_id的DOCTOR_OUTP。普通医生列表只含本人/未归属住院或受邀科室，护士/质控保留横向调阅。锁序住院→会诊→操作人，操作人FOR SHARE确保科室变更提交后重新判定，不把历史申请人或主管当受邀授权。既有出院会诊仍可补意见。

体检套餐管理限ADMIN/QUALITY，登记/团检创建限ADMIN/DOCTOR_OUTP/NURSE，总检限ADMIN或指定DOCTOR_OUTP。仅医师岗位登记默认自己，不可自行指定其他医生；有护理协调职责或管理员可选合法总检医生，未指定留null。管理员专属PUT /exam/records/{id}/examiner指定或调整总检医生；已完成记录不可重写或改派，记录→操作人行锁与改派串行。团检仍为单事务，中途失败回滚前续患者/记录。

体检读取按指定医生或护理登记人，多角色读取并集，总检写入不以护理/质控横向读取授权。团检名册按真实父团检及可见成员过滤，汇总在分组/上限前过滤，避免统计侧漏；ADMIN/QUALITY全域读取。新V180增加记录registrar_id/examiner_id和团检creator_id、查询索引及NURSE已有菜单34/父目录5绑定；不改旧Flyway、不增加菜单ID或配置。

列表纯增随访creator_id、会诊to_dept_id、体检registrar_id/examiner_id/examiner_name，前端同轮消费。原单体登记及团检创建兼容旧请求，新增可选examinerId；管理员改派体为examinerId。9916/9917/9918已前置登记，分别为非法总检医生、出院后申请会诊、非法受邀临床科室；原9901/9903/9905等状态码、9018主管拒绝及1005权限拒绝沿用。
