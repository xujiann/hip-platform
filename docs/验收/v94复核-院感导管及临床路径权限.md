# v94复核：院感导管及临床路径对象权限

状态：基线v1.8.12，2026-10-18验收通过，本地定版v1.8.13，尚未推送。

## 本轮口径

导管登记、日评估、拔管限ADMIN/NURSE；感染判定保留ADMIN/NURSE/QUALITY院感上报。写入必须真实用户，登记锁住院行并检查在院、串行重复同类型登记；子记录解析实际admission_id，父住院→导管顺序加锁，重查ACTIVE后评估/拔管/判定感染。保留历史已出院但未闭合导管补报/关闭，横向监测范围不缩为不存在的病区模型，不扩展DOCTOR_OUTP。

临床路径入径、变异/退出、完成限ADMIN/DOCTOR_OUTP，普通医生须实时当前主管或未归属。列表及变异统计在上限/分组前过滤；ADMIN/NURSE/QUALITY原横向反馈调阅保留，多角色医师写入仍按主管。子记录以数据库真实admission_id授权，不接受body中的归属字段；父住院→入径顺序锁定，移交和结束竞争重查。

新增PathwayService负责事务边界；入径及开嘱异常穿出服务事务后才转换业务信封。重复入径ON CONFLICT DO NOTHING返回9906，避免PostgreSQL事务abort后捕获异常继续。前端纯增消费入径doctor_id控制逐行按钮，重读和拒绝时清空旧结果并抑制旧响应。

V179只补现有医生患者管理34、护士院感专项61及父目录5/25的菜单绑定，不新增角色/菜单ID/配置/错误码；旧Flyway不改。4750–4754、9904/9906–9908、9003/9005/9018及1005保持各自语义。
