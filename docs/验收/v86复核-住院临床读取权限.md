# v86 住院临床读取权限复核（2026-10-16）

基线 v1.8.4。本轮仅收口病历列表、查房列表、补正历史、住院工作区和出院小结打印五个读取入口。

## 权限与实现

HTTP 原角色门槛保持。普通医生须解析到真实账号，且为源住院当前主管；未登记主管沿用既有允许规则。管理员与护士保留既有跨病案读取。每次按源住院实时归属检查，不因同患者或书写过历史记录取得其他住院的权限。拒绝走安全层 403/1005，不清除登录；住院不存在 9003。补正历史先核验 recordId 与 admissionId 父子关系，不存在/不匹配返回 9102，管理员和护士同样不能串路径。

医生站先清空旧工作区，全部请求成功后再显示患者；请求序号使快速切换中的旧响应失效。辅助完整性、账户和模板加载改为返回数据，与主工作区一起发布，避免部分请求提前改写另一个患者的页面。拒绝保持空工作区，共享客户端显示权限提示。

## 剩余优先级与边界

1. 高：入院、转床、出院/结算各入口的岗位与对象范围；需保留护理与收费流程，不能只删除角色。
2. 高：护理病区分配模型未建立，护士仍可跨病案读取；其余列表、检索、费用、体征、完整性预检及其他打印调阅入口未完成全库审计。本轮五入口修复不代表全局临床隐私隔离完成。
3. 中：其他诊断写入口与主管移交共用锁的竞态收口，须保留 QUALITY 编码操作；EMPI 全局搜索与其他调阅入口审计。
4. 后续：候选主管角色资格、普通医生住院医生站菜单、患者360同步按钮显示、未归属历史政策与住院结构化侧车。
