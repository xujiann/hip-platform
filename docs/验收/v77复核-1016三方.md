## 裁定
审计者：五个子要求（自动获取病情摘要 / 诊断、填写标本类型 / 采样部位、按流向自动获取执行科室）在开单界面与申请单两处均有真实实现并经 HTTP 与库态复现，建议上调，附九条须标注项。三个反驳者三票"不推翻但须标注"：
- **拆解**：独立拆成七项全部做实；核出规划节承诺"执行科室回显在该行申请信息"而实现只有提示闪一次（**已修**：工作区回填执行科室名、已开医嘱逐行有列）；诊断标签随病历区同步而摘要只预填一次，标注句须分写；每条检验医嘱一张申请单，说明须写清。
- **演示**：按培训脚本三处「⚠ 新 v1.7.3」逐步走零不通；演示库只有一个检验科室、tech01 无科室，分流演不出来（**已修**：bootstrap 种急诊检验室、tech01 挂检验科、一条「血常规·全血→急诊检验室」规则；培训脚本写明前置）；开关关闭时试算文案"无规则命中"不实（**已修**：返回体加 routeEnabled，试算写明"总开关已关闭"）；开关无独立界面（写入说明）。
- **口径**："忽略空格"只对半角成立，全角空格/NBSP 不命中（**已修**：规范化改 `[\s\p{Z}]+`，用例钉死）；预填会把「【结构化记录】」块带进临床摘要上纸而同纸"病史摘要"是剥过的（**已修**：预填复用 stripBlockMarks）；规则三元组无唯一索引、5913 靠时序（记债）；500 字只前端截（记债）。

**上调正偏离/无偏离**（wave36），说明按三镜头逐句限定重写；1026 说明中"字典维护页尚未开放该字段编辑"一句过时，同批改（结论不动）。

## 仍开（记技术债）
- `lab_route_rule` 同键三元组无唯一索引（并发建同键规则靠 select-then-insert 时序；PG16 可用 `nulls not distinct` 部分唯一索引，需发迁移号）。
- 临床摘要 500 字只前端截断，API 直传超长走通用 4091；标本/部位 32 字同。
- 申请单"病史摘要"（打印时取病历）与"临床摘要"（开单快照）默认同文两印，改病历后分叉——是否合并为一行待产品定。
- 流向只覆盖门诊检验类；标本类型未字典化；`lab.route.enabled` 无界面。
