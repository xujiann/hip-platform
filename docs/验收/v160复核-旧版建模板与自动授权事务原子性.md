# v160 旧版建模板与自动授权事务原子性复核

旧版创建模板将模板头和自动科室授权纳入同一事务。授权写入失败时模板头一并回滚，恢复后重试一次可得到完整模板与授权。原四字段请求、空成功返回和输入规则保持兼容。

## 修复与回归

`MedTechController.createTemplate` 仅增加既有 `@Transactional`。`POST /api/emr-templates` 的单参数签名、四字段请求、两条原 SQL、员工及范围校验、空成功返回、原名称正文与 templateType 口径均保留。HOSPITAL 仍不生成虚构授权。

无外层测试事务，使用真实 JWT 和 PostgreSQL。测试专用 JdbcTemplate 在自动授权写入时，先在实际连接上读到已写模板头，再执行原授权 SQL，用单次空 template_id 绑定触发真实 SQLState 23502。旧版 14 项中 5 项失败，均为五个维护岗位的失败授权遗留模板，另外 9 项兼容通过。修复后 14 项及相关范围、旧版、普通创建回归共 100 项通过。

授权失败沿既有 HTTP 200 / 4091 返回，模板头与授权完整投影恢复原值；取消测试故障后一次重试只新增一头一科室授权。失败请求和成功重试的七列审计分别保留。序列允许推进，不把序列连续性当作事务要求。
