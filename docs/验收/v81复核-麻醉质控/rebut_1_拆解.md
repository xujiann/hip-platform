## 四、可直接写入说明的限定句（逐句，无内部用语）

### 1424★
1. 「首台」指同一手术间同一日内入室最早的一台已开展手术（已登记开台时间或已完成），含急诊手术；未登记手术间的台次不参与首台统计。
2. 准点与延迟以实际开台时间对比排台时间判定，允许延后的分钟数由系统参数配置（默认 30 分钟）；开台早于排台计为准点；平台未记录麻醉开始时间。
3. 「延迟开台量」以分钟计，为判定为延迟的首台「实际开台时间 − 排台时间」分钟数的合计与平均值，从排台时间起算，不扣除允许延后的分钟数；延迟开台占比等于 100% 减去准点开台率（同一分母）。〔若补了延迟开台率列，后半句改为：「另单列延迟开台率。」〕
4. 「首台手术患者所属科室」取患者本次住院的登记科室，按日列出当日首台涉及的科室名称。
5. 排台或开台时间缺一的首台单列为「无法判定」，不计入准点率分母。
6. 另提供择期口径，统计范围为首台恰为择期手术的台次。〔若按 N2 修为「当日首个择期台次」，改为：「另提供择期首台口径，取同一手术间同一日内入室最早的一台择期手术。」〕
7. 取值明细为统计期内全部首台的逐台列表，逐台标注准点、延迟或无法判定，以及延迟分钟数。

### 1425★
1. 手术台数、总手术时长、总接台时长、平均接台时长按日统计，同时给出统计期合计；只统计已开展的手术台次（已登记开台时间或已完成）。
2. 「入室时间」以当日各手术间中最早一台的入室时刻，以及当日已登记入室时间的台数呈现，逐台入室时刻见取值明细；不提供入室时长（出室减入室）的统计。
3. 接台时长为同一手术间同一日内相邻两台「上一台出室至下一台入室」的间隔，跨日及时间重叠的相邻台次不计，间隔不设上限。〔若按 N3 加了上限，改为：「间隔超过 N 分钟的不计为接台。」〕
4. 手术时长为结束时间减开台时间，只统计两个时间都已登记、且结束晚于开台的台次，逐台保留到 0.1 分钟。
5. 各项时间统计只覆盖登记了相应时间点的台次。

### 1426★
1. 取消手术时由操作人员从申请、排程、入室前、术中四个阶段中选择取消阶段，并须填写取消原因。系统校验所选阶段与已登记时间点不矛盾：已排台的不能登记为申请阶段取消，已入室的只能登记为术中取消，术中取消须已登记入室时间。
2. 取消数量按取消发生的日期统计。页面登记取消时，以提交时刻为取消时刻；事后登记的取消可通过接口补录取消发生时刻，补录时刻不得晚于当前，术中取消不得早于入室时间。
3. 此前已取消、未记录取消时刻的历史台次，按其排台或建单日期统计，并单列其台数。
4. 已完成的手术不可取消；取消的手术记录保留，不计入手术台数类统计。
5. 每个阶段均可单独查看取值明细，逐台列出取消阶段、取消原因与取消时刻。

### 1428★
1. 统计范围为住院手术登记（日间手术按住院登记统计）。
2. 手术类别（择期、急诊、日间）在手术的术中信息中维护，手术申请时不填写；未维护类别的台次单列为「未填写」。
3. 「已开展」指已登记开台时间或状态为已完成的手术台次；只申请、已排台尚未开台以及已取消的台次不计入。
4. 每个类别均可单独查看取值明细，逐台列出手术类别。

### 1436★
1. 年龄按手术日期与出生日期计算，分为 1 岁以下、1–17 岁、18–44 岁、45–59 岁、60–74 岁、75 岁及以上六段，无出生日期的归为「未知」。
2. 性别取患者主索引登记的性别。
3. 每个年龄段与性别组合同时给出患者数（按患者去重，同一患者统计期内多次手术只计一人）与手术台次；同一患者统计期内跨越年龄段时在两段各计一人，故各段患者数之和可能大于统计期合计患者数。
4. 只统计已开展的手术台次（已登记开台时间或已完成）。
5. 每个组合均可单独查看取值明细，逐台列出患者、出生日期、手术时年龄、年龄段与性别。

### 1450★
1. 本统计为全院不良事件口径，不良事件登记未与手术记录关联，不区分麻醉、手术相关专项事件。
2. 「不良事件名称」为上报时选择的事件类型（跌倒、给药错误、压疮、管路滑脱、其他），不支持自定义事件名称。
3. 按事件发生日期落入所选时间段统计，单次查询跨度不超过 366 天；同时给出各级别数量与已处理数量。
4. 统计与取值明细在麻醉与手术质控页面提供，面向系统管理员与质控人员。
5. 取值明细逐条列出事件类型、级别、发生日期、科室、事件描述与处理状态。
