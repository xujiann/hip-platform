# v146 复核：模板读取权限快照

本轮已本地定版；数字事实以规划顶节及README为准。原始事实与SHA索引在work/v146-facts.json，独立审阅、命令退出及原证据由其绑定。

按id套用模板正文与读取授权名单各在一条SQL中取得当前actor科室及DB ADMIN画像、父scope/owner/USER与DEPT授权和实际返回数据，避免先校验可见性、后另取新正文或新授权集合的混合快照。正文enabled与scopeName从同一返回行判断；授权名单使用父LEFT JOIN，父不可见/缺失沿4066，可见无授权仍空列表，不把内部空行送入原公开DTO。

可见矩阵沿原规则：GLOBAL/HOSPITAL可见、owner可见、DEPT对ADMIN及同科可见、USER和DEPT授权叠加所有scope（含PERSONAL）。ADMIN仍无他人PERSONAL后门。正文套用要求启用，授权读取保留可见已停用模板；原排序、公开键、缺失及拒绝码保持。actor的null/missing内部调用边界保留，不新增员工enabled或读取岗位政策，HTTP仍走既有JWT与五岗门。无新迁移、菜单、配置、返回键、错误码或锁。

一致性以PostgreSQL语句快照为界：维护先提交、数据SELECT后开始则看到当前权限和数据；SELECT已开始时可返回当时已授权的合法快照，不承诺在回包途中撤回数据。公开维护回滚不影响原可读状态。读取不写模板、授权或任何临床表，不改变HEAD维护与字段及结构化保存的既有锁序。

新Java及前端/公共专项先于生产提交。正式旧/修后使用同一最终测试源码与class，真实JWT逐次清SecurityContext、没有外层测试回滚。只在测试DataSource/JDBC边界暂停准确的数据查询，由原公开维护入口完成提交或回滚后再释放；命中线程、SQL与参数、原维护回包及原业务结果留证。该证据属于JDBC语句边界调度，不冒称PG行锁竞争或使用sleep制造竞态，也没有生产测试钩子。拒绝须不返回秘密标记，允许结果须有一致的scopeName/名单；完整受监控业务投影及审计按专项实际范围归档，旧测试与Flyway保持。

原始测试和helper静态准备诊断单独保留，不计正式通过或缺陷对照。新测试预期数据的Jackson数值节点类型须经与HTTP相同JSON表示后逐键逐值比较，不能把数值相等但节点类型不同的夹具失败算作业务越权；正式旧实现对照在最终新测试SHA下重新完整执行。浏览器helper在任何执行前经独立审阅修正阶段文件名、审计finally落库等待及seed基线，所有旧稿静态记录留存。HEAD的/emr-templates读取不匹配原敏感GET前缀边界，不为正常或4066读取虚构新增审计；实际登录/维护写及401/403按原审计路径回账。

前端专项执行原门诊、急诊留观及模板维护完整SFC和真实共享client/Axios的受控传输，为兼容验证。普通列表通常已经带正文；已合法取得的缓存正文及授权名单不自动撤回，不把缓存本地套用称作新泄漏。只有缺正文时原fallback才读detail；原拒绝/草稿/会话及错误传播口径保持，未为本轮新增产品控件或改全局client。公共专项只证明公开可读投影，SQL全列另证，不把API测试当浏览器。
