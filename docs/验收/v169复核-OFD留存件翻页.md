# v169 OFD 留存件翻页复核

游标与列表在同一 SQL 快照内检查当前岗位、病历版本、来源摘要及原患者和住院关联，返回前沿用末次权限复核。无效格式返回 4000，未知或与目标不匹配的游标返回 5711，岗位和对象拒绝沿用原规则。无新增迁移、错误码、菜单或配置键。
