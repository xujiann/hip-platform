# v158 旧版建模板当前员工权限复核

旧版建模板接口按当前员工的启用状态、维护岗位、科室和管理员资格校验目标范围。请求认证后发生降岗或停用时，系统会在创建前重新校验，阻止沿用旧管理员资格建立共享模板。

## 权限与原契约

`POST /api/emr-templates` 复用现有 `templateMaintenanceActor` 查询，一次读取当前启用状态、五个维护岗位、科室及数据库 ADMIN 资格，再由原范围校验器判定全院或科室权限。控制器单参数签名、四字段请求、空成功返回、名称正文空白值和类型缺省规则由回归钉住。

真实 JWT 请求在员工画像 SQL 前暂停，通过公开员工接口独立提交降岗、失去维护岗位、转科或停用后继续。最终同测试源码在旧版得到 19 项中 7 项失败、12 项兼容通过。修复后 19 项通过。五个合法维护岗位及当前科室仍可建模板。拒绝请求的模板与授权投影均为空。

V42 历史夹具的默认 mock 用户名为 user，本轮指定已有 admin 账号，原断言保持。含 V38、V42、V45、V77 的专项合计 52 项通过。首次修复验证中的两条停用审计预期漏掉查询串，校正为完整 `/enabled?enabled=false` 后，在另两个全新库重复旧版与修复验证。
