## 授权规则
普通医生仅实时主管或未登记主管可操作，必须能解析到真实用户；管理员、护士保留三个流程的原有横向职责，收费员仅保留中间结算，转床/出院的 HTTP 角色门槛不扩大。兼任岗位按对应角色授权。护理病区分配模型尚未建立，不能宣称护士已被限定到病区。

服务事务中先锁住院行，再授权与执行业务，与主管移交共用同一行锁。操作人入参只用于记操作者，不作为授权主体。既有医师决策 guard 保持仅 ADMIN/DOCTOR_OUTP，不因新增护理/收费例外而放宽开嘱或修改诊断。可信内部无登录态调用沿用既有约定，HTTP 原角色门槛保持。不存在复用 9003、对象拒绝复用 9018，无新编号或迁移。
