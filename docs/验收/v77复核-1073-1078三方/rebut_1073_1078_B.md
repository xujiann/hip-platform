- **R3（改范围提示虚惊）**：编辑时只清空「所属科室」下拉（范围不变）会触发黄字与「原有授权已清空」提示，而后端按原科室处理、未清授权（`EmrTemplateView.vue:108,372-375` vs `EmrTemplateService.update:471`）。方向是虚惊不是漏清；建议前端把 `deptId==null` 视作未改。
- **R4（谁能授权 / 谁能用）**：科室模板由创建者或管理员授权，本科室其他同事不能；个人模板仅本人；管理员看不到也不能授权他人个人模板；被授权方只能查看/套用/复制。护士与医技不能进维护页，护士在界面上**无任何模板消费入口**，"人人可用"对护士只是 API 层。
- **R5（口径细节）**：全局与全院无行为差异、平台零预置；admin 建科室模板必须选科室（占位符「留空＝本人所在科室」对无科室账号失真）；无科室的质控只能建个人模板；用户管理页密码占位符「至少 6 位」与策略 8 位不一致（建账号前置路径上会撞 1102 一次）。
- **R6（改范围清授权是 HEAD 新语义）**：培训脚本与 CHANGELOG 尚无一句；维护页黄字已说清后果，评委不会被吓到，但讲师要知道"授给他人的要重授"。

## 结论 + 一句理由

**1073★：不推翻但须标注**（R1、R2、R4、R5）。理由：五账号 HTTP 实测的可见矩阵与说明逐句一致——四级可建（非管理员前两级置灰且后端 4066）、维护页列表/门诊下拉/住院下拉/按 id 取用四处口径同一、管理员见全部科室模板但看不到他人个人模板、HEAD 后老通道也套同一谓词；评委按菜单走每一步都走得到，唯一"看到的与说的不一致"是下拉把个人模板标成「（通用）」（R2），是标签文案而非可见性，不够推翻门槛。

**1078★：不推翻但须标注**（R1、R3、R4、R6）。理由：新建自动授权（授权行 + 隐含判定双保险）、授到科室/个人、被授权方只读可见、撤销即失效、自授权不可撤 4065、改范围清授权——全部在运行实例实测复现；走不通的只有**演示路径**：演示库没有第二科室的医生账号、培训脚本没写维护页，"他科不可见→授权后可见"要靴子落地须现场建号或借 quality01 演授权到个人，这是演示前置而非功能缺口。
