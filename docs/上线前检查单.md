# HIP 上线前检查单（v29，2026-08-28）

> 基准面：**真实医院下月上线，什么会挡路、什么会出事**。四个审查域并行（安全合规 /
> 业务完整性 / 前端全量 / 运行配置），每条结论附证据，处置分三类：
> **【立即修】**代码缺陷当轮闭环 ·**【补开发】**缺失能力 ·**【定责/延后】**外部边界或上线后。
>
> 总纲结论：**代码正确性扎实**（六轮审阅 140 项闭环、A 级并发实证、无可利用 SQL 注入、
> 认证核心稳固、前端 179 写调用 100% await）。真正的上线风险集中在两处——
> **① 安全的"菜单紧、接口松"越权面** ·**② 业务的收尾环缺失**（打印/导出/提醒/审批）。
