## 三、下一步计划（v11：三十二至三十四期，参数级查缺补漏）

### 第三十二期「设备全生命周期与后勤深化」（HRP 补强）
对准参数：设备维修/保养/计量、供应商证照、采购单据链、制度文件
1. **设备维修工单**：报修→派工→完成（院内/院外维修区分）、维修台账检索
2. **保养与计量**：保养计划+保养单（修改/作废）、计量台账与到期提醒（复用资质预警模式）
3. **采购单据链**：备货单→验收（发票补录/调整）→退货单，审核/作废/还原
4. **供应商证照**：生产商/供应商证照附件台账 + 到期预警
5. **制度文件库**：制度目录、上传、在线预览、下载（OA 扩展）
6. E2E 进 CI

### 第三十三期「护理与院感精细化」
对准参数：报卡闭环、发热监测、抽检评分、交接班
1. **传染病报卡全流程**：报卡（多类型）→审核→上报台账，全流程闭环状态机
2. **发热/体温日历**：患者体温日历视图（复用 inp_vital_sign）、发热天数；介入/术后 X 小时发热监测提醒
3. **护理班次维护 + 质控抽检**：院内标准班次类型字典；抽检计划+临时评分表单、评分曲线展示
4. **交接班记录**：护理/医生交接班（当班摘要+待办交接）
5. E2E 进 CI

### 第三十四期「门诊体验与药事分析」
对准参数：过号/改约、药品使用分析、集成适配器
1. **过号处理**：叫号过号→自动顺延队尾或入过号队列、大屏过号显示
2. **预约改约**：检查检验预约改时段/取消，批量操作
3. **药品使用分析**：全院/科室/中药使用汇总、抗菌药使用强度（DDD 雏形）、药品经费调查表
4. **集成适配器雏形**：文件适配器+数据库适配器、简单内容路由规则表（重型 ESB 参数归配套产品）
5. E2E 进 CI

三期完成后，参数口径预计：初评符合 ≈82%+，其余为配套产品参数（随采购响应）与外部条件项。
