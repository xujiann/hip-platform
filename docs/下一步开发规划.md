## 三、下一步计划（v9：二十九至三十一期，收尾 ◐ 深度项）

### 第二十九期「患者服务与支付闭环」
对准需求：自助服务(31)/移动支付(32)/互联网便民(90-92)/云胶片(66)
1. **聚合支付适配器**：PayAdapter SPI + Mock（微信/支付宝扫码），与医保通道同构——收费台出码、患者端账单在线缴费、支付流水留痕与日对账并入现有对账体系
2. **患者端报告补全**：检查(RIS)/病理报告查询（现仅检验）；危急值不直接外显、引导回院规则
3. **智能导诊**：症状关键词→科室推荐规则表 + 患者端入口
4. **云胶片对外链接**：检查报告分享短链 + 二维码（有效期/一次性控制），PACS viewer 地址透出
5. E2E（支付闭环+分享链接时效）进 CI

### 第三十期「病案与临床专科深化」
对准需求：病案统计(59)/临床路径(78)/手术麻醉(56)/体检(87)
1. **病案统计报表**：疾病谱 TOP20、手术例数统计、科室出院构成、ICD 构成——预置进报表引擎 + 病案页专属标签
2. **临床路径变异分析**：路径日程偏差记录（超期/退出+原因）、路径完成率与变异率统计
3. **麻醉记录单**：术中生命体征时间轴（复用 ICU 高频体征模型）+ 麻醉苏醒(PACU)记录
4. **体检团检**：单位团体建档、批量导入体检、团检汇总报告（异常率横向对比）
5. E2E 进 CI

### 第三十一期「移动端与等保强化」
对准需求：移动应用(93-95)/信息安全(20-23)
1. **移动护理/查房 H5**：护士执行、生命体征录入、医生查房关键页响应式改造（PWA manifest 已就绪）
2. **数据脱敏**：列表场景手机号/证件号脱敏展示，按角色授权见明文（等保三级要求）
3. **等保补强**：敏感操作（退费/删除/授权变更）二次确认+强留痕、会话超时策略、密码有效期提醒
4. E2E 进 CI

预计三期完成后：✓ 约 99 项（软件可做项全部收口），剩余 6 项外部条件 + 2 项服务项。
