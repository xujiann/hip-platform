## 查询现状的命令

```bash
grep -rhn "R.fail(\|new BizException(\|new InpException(\|new LegacyException(" --include=*.java modules platform server/src/main datacenter | grep -oE "(fail|Exception)\(([0-9]+)" | grep -o "[0-9]*" | sort -n | uniq -c | sort -rn | head
```

计数 >1 且跨文件的码需人工确认是否同义复用。
