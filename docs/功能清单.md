# HIP 标准平台功能清单（v1.0，2026-08-06）

> 面向多医院实施与选型沟通：全部功能按业务域列出，标注**可整体关闭**（模块开关，实施时按院启停）
> 与**依赖外部条件**（接入点就绪，等资质/SDK 到位）。菜单以 sys_menu 实表为准（55 个功能页 + 患者端 + 打印）。
> 权限：8 内置角色（管理员/医生/护士/收费/药师/医技/质控院感/运营后勤）按页绑定，可按院增删。

## 一、患者服务
| 功能页 | 核心能力 |
|---|---|
| 患者建档 | EMPI 主索引、身份证推算性别生日、同证件号幂等、按角色脱敏（仅管理员明文） |
| 患者管理 | 临床路径入径/变异、随访、体检个检团检（异常率对比）、满意度 |

## 二、门诊业务（18 页）
| 功能页 | 核心能力 | 备注 |
|---|---|---|
| 门诊挂号 | 排班号源、原子占号防超挂、退号联动收费拦截 | |
| 医生排班 | 号源与容量管理 | |
| 门诊医生站 | 接诊/电子病历/诊断/统一订单行开单，合理用药五重拦截（过敏交叉/重复/DDI/年龄/抗菌分级） | |
| CDSS 提醒 | 规则库可维护（DDI/剂量疗程/年龄/诊断建议），嵌入开单与病历链路 | 可整体关闭 |
| 门诊收费 | 结算/退费/重收，医保通道联动（分割/审核/上传/冲正） | |
| 扫码支付台 | 聚合支付出码/作废/回调（PayAdapter SPI） | 真实支付商为外部条件 |
| 药房发药 | 原子扣库存、退药、按处方聚合叫号 | |
| 审方工作台 | 药师审方状态机（非强制模式，拒绝即作废） | |
| 医技执行站 | 检查检验执行、结果录入、报告查询 | |
| LIS 工作台 | 标本流转（采集→接收→上机→发布），发布自动回传执行+危急值 | |
| RIS 报告 | 检查报告审核发布、按项目归类心电/内镜/超声 | |
| 叫号大屏 | 候诊叫号、过号顺延/重呼、语音播报（Web Speech） | |
| 预约与叫号 | 检查检验时段预约、改约/批量取消、药房/检查/检验三队列 | |
| 急诊预检分诊 | I-IV 级分诊队列、急诊留观（占床/观察记录/去向） | |
| 门诊护士站 | 皮试（阴性放行）、输液执行与巡视 | |
| 专科流程 | 病理标本流转（取材→核收→诊断发布）、ICU 密集记录（GCS、24h 出入量） | |

## 三、住院业务（8 页）
| 功能页 | 核心能力 | 备注 |
|---|---|---|
| 住院登记 | 原子占床、押金、住院号 | |
| 住院医生站 | 记账式医嘱、住院病历（入院/病程/出院小结）、CA 签名冻结（SPI） | CA 产品为外部条件 |
| 护士执行 | 医嘱执行扣库存、生命体征、体温单图表、护理风险评估（Braden/Morse 分级预警） | |
| 护理白板 | 在院总览、护理级别、交接班 | |
| 出院结算 | 押金冲抵、未执行医嘱拦截、医保出院上传（行级分割） | |
| 手术麻醉 | 手术申请/完成、麻醉记录单（术中时间轴 + PACU Steward 出室判定） | 可整体关闭 |
| 用血管理 | 申请→审批→发血→输血全状态机 | 可整体关闭 |
| 移动工作台 | 移动护理体征录入、移动查房（H5 单列） | |

## 四、运营管理（7 页）

|---|---|---|

| 设备管理 | 维修工单、保养计划、计量到期预警、采购单据链、供应商证照预警 | |

| 人事管理 | 员工档案、工资导入与个人查询、培训/继续教育学分、考勤补卡、招聘 | 可整体关闭 |
| 药事分析 | 用药 TOP、中西药构成、抗菌药 DDD 使用强度、月度经费 | |
| 日结报表 | 按支付方式日结、CSV 导出、交款核对（收款员/异常明细） | |
| 窗口与科研 | 服务窗口维护、科研项目与成果转化台账 | |

## 五、基础数据（3 页）
药品目录 / 收费项目（含调价留痕）/ 药库管理（进销存统一流水、退药）——均支持 **CSV 批量导入**（实施工具）。

## 六、数据中心（11 页）
| 功能页 | 核心能力 | 备注 |
|---|---|---|
| 患者360视图 | CDR 三类文档聚合、增量同步、CDA 骨架、全文检索 | |
| DRG 分析 | CHS-DRG 入组（MCC/CC 细分）、CMI、费用/时间消耗指数、支付模拟与高低倍率 | 可整体关闭；官方目录为外部条件 |
| 病案统计 | 疾病谱/手术/科室/ICD 构成、病案首页与归档、编码率 | |
| 质控中心 | 时限质控、抽检评分曲线、不良事件 | |
| 管理与院感 | 院感上报、评审指标 9 项、数据填报审批 | |
| 院感专项 | 三管监测（VAP/CLABSI/CAUTI 千日率）、现患率调查、传染病报卡闭环 | |
| 护理院感精细 | 体温日历、术后发热监测、护理排班与质控评分 | |
| 单病种上报 | ICD 前缀自动入组、上报卡 | |
| 数据治理 | 数据元（WS 363）、术语映射、订阅推送、数据质量规则 | |
| 数据标准与报表 | 自定义报表引擎（SELECT 白名单）、指标快照 | |

## 七、集成平台（3 页）
| 功能页 | 核心能力 | 备注 |
|---|---|---|
| 集成监控 | HL7 V2/MLLP 报文、出入站留痕、危急值处理闭环 | |
| 医保管理 | 目录对照（CSV 导入+对照率）、费用分割（起付线/封顶线待遇模型）、智能审核、对账（每日自动+差异工单）、DRG 支付模拟联动 | 可整体关闭；省 SDK 为外部条件 |
| 适配器路由 | 文件/DB 适配器注册、内容路由规则 | 重型 ESB 归配套产品 |

## 八、系统管理（5 页）
用户/科室/角色权限（菜单树授权）/审计日志（敏感操作过滤）/运维中心（健康告警、慢接口、故障工单、巡检、备份时效）。

## 九、患者端（H5，独立入口 /portal）
预约挂号、待缴费出码支付、检验检查病理报告（危急值遮蔽为回院提示）、报告分享短链（匿名脱敏限时）、智能导诊。微信实名/电子健康卡为外部条件。

## 十、平台横切能力
机构参数化（院名/品牌）、**模块开关**（六域：DRG/CDSS/医保/用血/人事/手麻）、JWT+RBAC、密码策略与防爆破、
写操作全量审计、慢接口观测、每日备份与恢复演练脚本、打印数据集、PWA。
