# ADR-0004 医保局案件查办系统（bureau）

日期：2026-08-06　状态：已采纳（2026-08-08 由 ADR-0003 重编号——与「实施定制层规约」编号冲突，本篇让号）

## 背景

在 HIP 单体仓库内新增一套**市级医保局使用的基金监管案件查办系统**。与医院 HIS 是两个部署主体（监管方 vs 被监管方），但技术栈与底座能力（认证/RBAC/菜单/配置/审计）完全同构。

### 依据文件（实现蓝本）

1. **《医疗保障行政处罚程序暂行规定》（国家医疗保障局令第4号，2021-07-15 施行）**——全流程程序法定依据，62 条全文已核读。流程与时限：
   - 线索核查：发现线索/收到材料起 **15 个工作日**内核查并决定是否立案，经主要负责人批准可延长 15 个工作日（第14条）
   - 立案标准：明确违法嫌疑人 + 涉嫌应予处罚 + 本部门管辖（第15条）；执法人员**不少于 2 人**（第16条）
   - 证据 8 类（第19条）；现场笔录、询问笔录（第20/24条）；专家评审（第25条）
   - **先行登记保存**：负责人批准，**7 个工作日**内作出处理决定；紧急先采取、24 小时内补批（第26-28条）
   - **封存**：不超过 **30 日**，可延长 30 日（第29-33条）；协查函 15 日（第34条）
   - 调查终结报告 6 项内容（第36条）
   - **法制审核**：罚款数额较大/听证案件/疑难复杂/重大公共利益等必经，未经审核或未通过**不得作出决定**（第37条）；审核 **10 个工作日**+10（第40条）；意见 5 类（第39条）
   - 处罚**告知**+陈述申辩+听证；**不得因陈述申辩而加重处罚**（第41条）
   - 中止调查 5 情形（第42条）、终止调查 3 情形（第47条）
   - 负责人审查后 5 种决定：处罚/不予处罚/不成立/移送其他部门/移送司法（第43条）；重大案件**集体讨论**（第44条）
   - **办案期限：立案起 90 日**，负责人批准 +30 日，集体讨论再延最长 +60 日；检测检验/鉴定/听证/公告/专家评审时间不计入（第45条）
   - 简易程序：公民 ≤200 元、法人/其他组织 ≤3000 元可当场处罚，7 个工作日内备案（第48-51条）
   - 执行：当场收缴限 ≤100 元或事后难以执行（第52条）；基金退回专户、罚款上缴国库（第53条）；暂缓/分期（第54条）；逾期**每日按罚款数额 3% 加处罚款且不超过本金**、申请法院强制执行（第55条）
   - 结案 4 情形 + 结案报告（第56条）；归档**一案一卷**（第57条）；决定书当场交付或 **7 个工作日**内送达，可电子送达（第59条）；处罚决定公开（第46条）
2. **《关于规范苏州市医疗保障基金监督执法案件案由的通知》（苏医保督〔2024〕1号）**——案由字典蓝本：4 类违法主体（经办机构/定点医药机构/自然人/其他主体）× 9 种案由 × **35 项违法情形**，全部作为种子数据；案件命名规则：调查阶段"违法主体+**涉嫌**+案由+案"，决定后去"涉嫌"。
3. 生态环境部《生态环境行政处罚办法》原链接已 404，其程序结构与医保局令第4号同源自《行政处罚法》，以医保局令为准，不另行引用。

## 决策

1. **同仓独立应用**：新增 Maven 模块 `bureau/server`（`cn.hip.bureau`），仅依赖 `hip-platform-core` 复用认证/JWT/RBAC/菜单/sys_config/审计查询；独立数据库 `hip_bureau`、独立 Flyway 序列（B 侧 V1 起）、独立端口 **8090**。医院 `server` 不依赖 bureau，互不可见。
2. **前端独立应用** `frontend/bureau`（Vite + Vue3 + Element Plus 按需），复制 shell 的登录/布局/客户端骨架，代理指向 8090；不与医院前端混包。
3. **域模型以法条为骨架**：线索 case_clue → 案件 case_file（状态机）+ 办案人员/证据/文书/期限扣除/法制审核/告知听证/集体讨论/决定/送达/执行 子表 + 案由字典 case_cause（35 项种子）。
4. **法定规则做成硬校验**（错误码 2xxx）：执法人员≥2、简易程序限额、未经法制审核不得决定、告知前置、陈述申辩不加重、办案期限 90+30+60（扣除期间不计入）、当场收缴 ≤100、加处罚款 3%/日封顶本金、结案条件（执行完毕/法院受理/无须执行）。
5. **工作日计算**：跳过周六周日（法定节假日暂不建表，留 sys_config 扩展）。
6. 阈值走 `sys_config`：法制审核"罚款数额较大"阈值、听证告知阈值、机构名称、文号前缀，实施时按地市调整。

## 状态机

```
线索: PENDING →(延期)EXTENDED → FILED / REJECTED
案件: INVESTIGATING ⇄ SUSPENDED(中止)
      INVESTIGATING → TERMINATED(终止，终态)
      INVESTIGATING → REPORTED(调查终结) → NOTIFIED(已告知/听证) → DECIDED(已决定) → DELIVERED(已送达) → CLOSED(结案)
      简易程序: 立案后直接 DECIDED（限额校验）
```

## 后果

- 医保局产品与医院产品共享底座演进（core 改动两边受益），但部署、数据、发布节奏完全独立。
- 回归：`tools/e2e-bureau-case.py`（全流程 + 全部守卫用例）。
- 未来扩展：文书 PDF 套打、电子送达签收、与智能监控系统（大数据筛查线索）对接、行刑衔接移送公安接口。
