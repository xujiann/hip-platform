# 种子数据三类分层清单（产品化一期，2026-08-06）

> 原则（产品化方案 §三.1）：**A 平台必需**随 Flyway 装机即有；**B 行业基线**默认可用、实施可整表替换；
> **C 演示数据**只进演示环境。历史迁移不改（Flyway 纪律），分层通过「新库初始化路径」实现：
> 迁移照跑（含 A/B），实施用 init-hospital.py 覆盖 B、绝不运行 bootstrap-demo（C）。

## A · 平台必需（留 Flyway，随产品版本发布）

| 表 | 内容 | 说明 |
|---|---|---|
| sys_menu / sys_role_menu | 全量菜单树与 8 角色绑定 | 平台骨架，随版本演进 |
| sys_role | ADMIN/DOCTOR/NURSE 等 8 角色 | 角色基线，按院可增删绑定 |
| sys_config | 默认参数（机构/比例/开关/阈值，32 键，以配置手册为准） | 键集合属平台；**值**属 L2，实施覆盖 |
| sys_dept / inp_bed | 内科门诊/内科病区 + 6 床 | ⚠ 属「最小可运行样例」，实施应按院方结构补建（init-hospital），已有样例保留无害 |
| dg_data_element / dg_term / dg_metric_def / dg_report_def | 数据元（WS 363）/术语框架/内置指标/报表定义 | 标准框架数据 |

## B · 行业基线（迁移带默认，实施可整表替换 / init 工具导入院方目录）

| 表 | 内容 | 替换途径 |
|---|---|---|
| md_drug / md_charge_item / md_icd | 药品 10 / 收费项目 13 / ICD-10 简表 | init-hospital 字典 CSV（upsert 覆盖同码，缺省样例可停用） |
| yb_catalog_map | 医保对照 13 项种子 | /insurance/catalog/import CSV |
| drg_group_def / drg_cc_list | CHS-DRG 简化 10 组 + MCC/CC 目录 | 官方目录整表替换后 regroup-all |
| cdss_ddi/dose/age/suggestion | CDSS 示例规则四表 | 商用知识库接入替换数据源 |
| triage_guide / sd_disease_def / nur_shift_type / svc_window / int_adapter / int_route_rule / oa_doc_file | 导诊规则/单病种/班次/窗口/适配器样例/制度样例 | 业务页维护，按院增删 |

## C · 演示数据（生产库禁止出现）

| 来源 | 内容 |
|---|---|
| tools/bootstrap-demo.py | 演示患者（Test/张三）、7 个 Demo1234 演示账号、体检套餐、抽检计划等 |
| CI「准备基础数据」步骤 | 1/2 号患者（仅 CI 库） |
| 各 e2e-*.py 造的数据 | 仅测试/演示实例运行 |

**结论**：43 个迁移中不存在 C 类数据（演示数据从第一天起就走脚本不走迁移，此次审计确认）；
A/B 混排存在但无害——B 类均可被 init-hospital / 业务页 / 官方目录整表覆盖，新医院实施路径为：
`Flyway 自动跑（A+B 默认）→ init-hospital.py（院方 B 覆盖 + 组织/账号/开关）→ 不跑 bootstrap-demo`。
